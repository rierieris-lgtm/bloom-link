# RIE / BLOOM LINK トーン&マナーガイド

サイト内の全コピー（Top / Garden / Compass Program / Business Program / Travel / Contact）から抽出したRIEのブランドボイス・ビジュアルトンマナのリファレンス。

## 1. ブランド人格（誰が話しているか）

RIEは「教える人」ではなく「一緒に歩く伴走者」。

- 元・大手企業秘書｜フレンチオーナーシェフの妻｜二児の母｜35〜40カ国渡航
- 3つの現場（組織を支える／夫の店の経営に関わる／ゼロからオンラインビジネスを作る）を経験してきた「実践者」であり、理論より実体験で語る
- 出発点は「欠如」ではなく「好奇心」。**"今も満たされている。でも、この先にどんな景色があるのか見てみたい。"** がブランドの核心の一文
- 旅と内省（内観）の両輪で人を変えてきた人、という自己認識

## 2. トーンの原則

1. **背中を押すが、決めさせない**：「〜しませんか」「一緒に」「あなたのペースで」。命令形・断定形は避ける。
2. **許可の言葉を使う**：「緩めていい」「完璧でなくても」「答えは一つじゃなくていい」。読み手を評価・審査しない。
3. **一人称は「私」、二人称は「あなた」**：Rie自身が語る一人称の述懐（プロフィール文）と、読者に語りかける二人称（キャッチコピー・CTA）を使い分ける。
4. **対比のリズムで書く**：「〜じゃない。〜だ。」「教わる場所ではありません。」のように、否定→肯定の型で本質を提示する。
5. **体言止め＋読点の詩的な改行**：一文を短く切り、`<br />`で改行して余白のリズムを作る。
   - 例：「自分の軸を育てる、6ヶ月の旅。」
   - 例：「オンラインで収益を作る、6ヶ月の実践プログラム。」
6. **売り込まない**：機能の羅列より「その先にある変化」を語る。価格は明快に事実だけ提示し、煽らない。
7. **敬語は柔らかく**：「〜です・ます」基調だが、硬い書き言葉やビジネス敬語（「〜させていただきます」等）は使わない。

## 3. キーワード辞書

頻出し、ブランドの世界観を支えるコアワード：

| カテゴリ | 語彙 |
|---|---|
| 自己 | 自分の軸／自分で選ぶ・決める／自分に還る／本音／内側／余白 |
| 旅・移動 | 景色／旅路／羅針盤／扉が開く／広がる |
| 成長・関係 | 伴走／一緒に／寄り添う／育てる／仲間／咲く（Blooming） |
| 状態変化 | 手放す／整える／解き放つ／踏み出す |

**避ける言葉**：「絶対に」「必ず」「稼げる」といった断定・煽り系の売り文句、堅いビジネス敬語、過度な専門用語。

## 4. 文体サンプル（実例）

**キャッチコピー（体言止め＋対比）**
> 世界を知り、自分に還る。
> ここは、自分に戻る場所。
> 答えは、あなたの中にある。
> 旅は、観光じゃない。人生を広げる体験だ。
> アイデアを、実践へ。

**プロフィール文（一人称の述懐）**
> 旅に出るたびに、世界が広がった。違う文化、違う価値観、違う生き方——旅で出会うたびに、「人生の選択肢って、こんなにあるんだ」と思った。
> 人生の選択肢は、自分の周りの"普通"でできている。環境が変われば、選択肢も変わる。自分で選んだ人生を、一緒に作っていきたい。

**CTA（呼びかけ・許可）**
> まだ知らない自分と世界に出会う旅を、ここから一緒に始めませんか？
> どんな旅がしたいか、まだわからなくても大丈夫。気になることをLINEで気軽に聞いてください。

**説明文（否定→肯定の型）**
> Blooming Compass Programは、答えを教わる場所ではありません。
> 心も身体も、緩めていい。自分のペースでいい。

## 5. セクション見出しの型

- 英語の小見出し（uppercase・字間広め）＋日本語の大見出し（明朝系・細字・時々イタリック）という2段構成が全ページ共通
  例：`Concept` → 「ここは、自分に戻る場所。」／`Story` → 「経験はすべて、誰かの力になれる。」

## 6. ビジュアルトンマナ

**カラーパレット**
| 用途 | Hex | 役割 |
|---|---|---|
| Forest（ブランドメイン） | `#2B5F7A` | 見出し・ボタン・信頼感 |
| Terra（アクセント） | `#C4714A` | CTA・強調・温かみ |
| Ecru（背景） | `#FAF8F3` | ベース背景、余白の質感 |
| Gold | `#C9A96E` | 濃色背景上のラベル装飾 |
| Ink | `#2A3540` | フッター・本文濃色 |
| Muted blue-gray | `#7A8E9A` / `#8A98A5` | 本文・補足テキスト |

**タイポグラフィ**
- 見出し（欧文/数字）：`Cormorant Garamond`（セリフ、weight 300、時々イタリック）— 上品で軽やかな余白
- 本文（和文）：`Zen Maru Gothic` または `Noto Sans JP`（weight 300〜400）— 柔らかく丸みのある印象

**レイアウトの型**
- 小見出しは英語・大文字・字間広め（`letter-spacing: 0.3em`程度）
- 本文行間はゆったり（`line-height: 2〜2.8`）で「余白」そのものが世界観を体現
- ボタンは角丸フル（pill）、ホバーでわずかに浮く程度の控えめなモーション
- セクション区切りは淡いグラデーションや1pxの細い罫線のみ、強いボーダーは使わない
