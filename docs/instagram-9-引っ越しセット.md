**ChatGPTなど、別のツールに渡すための一式。**

## 0. 先に読んでください（大事な3点）

**1. 日本語の文字は画像生成に任せない。**
画像生成AIは日本語を正しく描けません。実際に試した案では
「充金しよ、あい」「並んなね売もだてか」のような崩れた文字が出ていました。
**文字は必ず `npm run ig:render` で入れます。**
ChatGPTに頼むのは、写真そのものか、写真の構図・世界観の案までにしてください。

**2. AI生成写真を主役にしない。**
確定資料に「本人が実際に撮影した写真をブランドの大きな資産として使う」とあります。
AI生成写真は、構図を探すためのラフや、どうしても素材がない箇所の検討用にとどめます。

**3. 絶対に暗くしない。**
写真全面に暗いフィルター＋白文字の案には戻しません。理由は §3 に実験結果があります。

**4. 01・02・03はすでに投稿済みです。**
この3枚が最終的な見本です。仕様と食い違うところがあれば、**投稿済みの3枚が正しい。**
そこから確定したことは §3 にまとめてあります（フッターなし／サブは任意／小さな飾りは可）。

## 1. このアカウントの中心

> **仕事を軽くして、人生を広げる。**

コピー・写真・レイアウトを足すときも直すときも、
必ずこの一文に接続できるかを先に確認します。接続できないものは入れません。

AIや効率化そのものを売るアカウントではありません。
仕事を整理して、AI・仕組み・チームに渡して、**時間と心の余白をつくる。**
その余白で人生の選択肢を増やす、という話です。

### 発信者

Rie。40代。

- 約4万人規模のグローバル企業で会社員22年（社長秘書・全社リスクマネジメント統括）
- その後オンラインで副業・起業。オンライン秘書として主婦や副業女性とチームをつくる
- 50件以上のプロモーション支援・秘書業務・事業支援
- 経営者の妻としてレストラン経営を支える。子育て、家族のことも
- 現在は企業・経営者・個人事業主へ、業務整理／AI活用／仕組み化／チームづくりを提供

**「会社員が会社を辞めて自由になりました」という単純な話にしません。**
妻・母・娘・会社員・店の経営、どれも大切で削れなかった。
だから「もっと頑張る」ではなく「仕組みを変える」を選んだ、という順番です。

### 9投稿は一本の物語

```
人生 → 違和感 → 選択 → 働き方 → 仕組み → AI → 人 → 世界 → 経営者支援 → 人生の選択肢
```

01から09まで読むと「なぜこの人が今この仕事をしているのか」がわかる構成です。
独立した9投稿としては設計しません。

## 2. 仕様

| 項目 | 値 |
| --- | --- |
| サイズ | **1080 × 1350 px（4:5）** |
| 余白 | 左右 90px ／ 上下 96px |
| 日本語（見出し） | Noto Serif JP・Light(300)・74〜84px・行送り1.5・字間 0.02em |
| 日本語（サブ） | Noto Sans JP・Light(300)・25px・行送り1.9 |
| 英字（カテゴリー） | 17px・字間 **0.34em**（大きく開ける）・全部大文字 |
| 英字（09の署名） | Italianno |

### 色

| 名前 | 値 | 使うところ |
| --- | --- | --- |
| IVORY | `#FAF8F3` | 地色・文字を載せる面 |
| NAVY | `#2B5F7A` | 見出し・本文の文字 |
| CHARCOAL | `#3A4754` | 補助の文字 |
| MUTED | `#6E8090` | サブコピー |
| FAINT | `#94A3AF` | カテゴリー英字 |
| GOLD | `#C9A96E` | 罫線・数字・小さな飾り **だけ。少量** |

写真は元の色を活かします。加工は `saturate(1.04) brightness(1.03)` のみ。

### 文字の階層（全枚で共通）

```
CATEGORY（英字・小さく・字間を開ける）
        ↓ 30px
見出し（明朝・2〜3行）
        ↓ 28px
くすみゴールドの罫線（幅300px・不透明度75%）
        ↓ 24px
サブコピー（1〜2行）
```

罫線が**見出しとサブの間**に入るのが要点。投稿済みの01・02がこの形。

**この塊の形と間隔は9枚すべて同じ。** だから置き場所を変えても1つの作品に見えます。

### フッターは入れない

以前は下に「仕事を軽くして、人生を広げる。／BLOOM LINK」を置く設計でしたが、
**投稿済みの01・02・03はどれも入れていません。** 毎回入れると表紙の下に説明が居座って、
写真の余白が死にます。シリーズの一文は見出しか本文で必ず出るので、表紙で繰り返す必要がありません。

例外は**09の署名（Rie）だけ**。物語を本人の名前で閉じるためです。

### サブコピーは任意

**03はサブを置いていません。** 見出しだけで足りる回は置かなくて構いません。
写真が強い回ほど、文字は少ないほうがもちます。置かない場合は罫線も一緒に外します。

### 小さな飾りは足してよい

03には、カテゴリーの上に**細い罫線＋小さなゴールドの光**、
左下に**細い線画の植物**が入っています。この程度なら足して構いません。

- 線は細く（1〜1.3px程度）、色はくすみゴールドか紺
- 置くのは**余白の中だけ**。写真や文字に重ねない
- 1枚に多くて2つ。全部の枚に入れると装飾が主役になります

### 目指す世界観

明るい／知的／上品／自然／国際的／余白／信頼／洗練／大人っぽい

## 3. 文字の置き場所は4種類（ここがリズムをつくる）

**同じ「写真全面」でも、文字をどこに置くかで印象が変わります。**
全部を同じ位置にすると、統一感を通り越して単調になります。

| 置き場所 | 見え方 | 選ぶ基準 |
| --- | --- | --- |
| **下に帯** | 写真は上側。下にアイボリーの帯 | 被写体が写真の**上寄り**にあるとき |
| **上に帯** | 文字が上。写真は下側 | 被写体が**下寄り**のとき／上部に隠したいものがあるとき |
| **浮かぶ箱** | 文字が箱に入り、写真が四方に残る | 縦位置で余白のある写真。雑誌のページのように見える |
| **縦割り** | 左がアイボリー、右が写真 | 被写体が**片側**に寄っているとき。02・03がこの形 |

**アイボリー面の幅は固定しません。** 写真の被写体がどこから始まるかで決めます。
投稿済みだと02が約30%、03が約41%。文字が入る幅が変わるので、見出しの字数もそれに合わせます。

- 幅が狭いとき（30%前後）… 見出しを**3行**に割って**56px程度**まで落とす（02がこの形）
- 幅が広いとき（40%前後）… **2行**のままで大きく置ける（03がこの形）

2行のまま狭い面に入れると、語の途中で折り返して読めなくなります。

写真との境目は**硬い直線にせず、46px程度かけて溶かします。**

**帯の位置は好みではなく、写真の被写体がどこにいるかで決まります。**
帯は画面の約45%を覆うので、被写体のいる側に帯を置くと人物が消えます。

帯の境目は、アイボリーから写真へ110pxかけて溶かします（硬い線にしない）。

### 実験の結果（この4通りを試しました）

| 試した型 | 結果 |
| --- | --- |
| 白文字・写真を暗くしない | 空の上は読めるが、建物や人に重なると崩れる。サブコピーは読めない |
| 白文字・写真を暗くする | 読めるが、空の青と地面の明るさが死ぬ |
| 紺文字・写真の明るい部分に置く | 写真が変わると成立しない（緑の中では完全に読めない） |
| **写真全面＋明るい帯** | **どの写真でも読めて、色もそのまま残る** ← これを採用 |

## 4. 9枚のグリッド設計

Instagramのプロフィールは**新しい投稿が左上**に来ます。
01から順に投稿すると、グリッドではこう並びます。

```
09 08 07
06 05 04
03 02 01
```

**だから表紙に 01〜09 の番号は入れません。** 番号が逆から読まれて、
はじめて見た人には左上の「09」が何なのかわからないからです。
順番はキャプション冒頭の「01｜」で伝えます。

物語の順に並べた設計はこうなっています。

```
01 箱        02 縦割り    03 縦割り     ← 投稿済み
04 手順の図  05 上帯      06 箱
07 上帯3枚   08 数字      09 下帯
```

写真は7枚、文字ものは2枚（04・08）。
**写真を使わない回があるので、素材が揃わなくても投稿が止まりません。**

### 残り6枚をどの型にするか

プロフィールでの実際の並びは逆なので、こうなります。

```
09 下帯      08 数字      07 上帯3枚
06 箱        05 上帯      04 手順の図
03 縦割り    02 縦割り    01 箱        ← 投稿済み
```

見るのは**左右の隣と、真上・真下**です。同じ型が接すると繰り返しに見えます。

| 位置 | すぐ上が | だから |
| --- | --- | --- |
| 04 | 01（箱） | **箱にしない**。手順の図なので問題なし |
| 05 | 02（縦割り） | **縦割りにしない**。上帯にする |
| 06 | 03（縦割り） | **縦割りにしない**。箱にする（01の箱とは接しません） |

**下の段は縦割りが2枚続いています。** 03と02が両方とも「左アイボリー・右写真」なので、
並ぶと同じ形の繰り返しに見えます。すでに投稿済みなので直せませんが、
**04〜09では縦割りをしばらく使わない**ほうが全体のリズムが戻ります。
使うとしても07以降、離れた位置にしてください。

## 7. 絶対に避けること

- 全体を暗くする／黒中心にする／「高級感＝暗い」と解釈する

- 苦労話中心にする
- 40代女性向けだけに狭めすぎる

## 8. ChatGPTに頼むときの文例

### 写真そのものを探す・作る場合

```
以下の条件に合う写真の構図を提案してください。実際に撮影するための指示として書いてください。

用途: Instagram投稿の表紙（1080×1350、4:5）
テーマ: 「AIを使う前に、やることがある。」
必要な条件:
- 明るい自然光。暗い加工はしない
- 被写体が画面の下寄りにあること（上40%に文字を載せるため）
- 手元・キーボード・仕事をしている場面
- 世界観: 明るい／知的／上品／自然／国際的／余白
- 色: 写真の元の色を活かす。青・緑・自然光を残す
```

### 表紙のラフを見たい場合

```
Instagram投稿の表紙のラフを作ってください。

サイズ: 1080×1350（4:5）
構成: 写真を全面に敷き、下側にアイボリー(#FAF8F3)の帯を置く。帯は画面の約45%
文字は帯の中に紺色(#2B5F7A)で置く。写真は暗くしない
下に屋号やタグラインのフッターは入れない

※ 日本語の文字は崩れるので、文字はダミー（■■■■）で構いません。
   実際の文字はこちらで入れます。見たいのは写真と帯のバランスです。
```

### 投稿済みの3枚に合わせてほしい場合

```
すでに投稿した3枚の表紙を添付します。この3枚と並べて同じ作品に見える表紙を作ってください。

守ること:
- 1080×1350（4:5）
- 写真は暗くしない。元の色を残す
- 文字はアイボリー(#FAF8F3)の面の上に紺色(#2B5F7A)で置く
- 屋号やタグラインのフッターは入れない
- くすみゴールド(#C9A96E)は罫線と小さな飾りだけ。少量
- 英字はカテゴリー1つだけ。主役は日本語

避けること:
- すでに使った形（浮かぶ箱・縦割り）をそのまま繰り返す
- 全体を暗くする／黒を中心にする
- 装飾を増やす

※ 日本語はダミー（■■■■）で構いません。見たいのは写真と面のバランスです。
```

**日本語をダミーにするのが要点です。** 崩れた日本語が入ったラフは判断に使えません。

## 9. 戻ってくるとき

ラフや写真ができたら、写真ファイルを渡してもらえれば組み込めます。

```bash
npm run ig:photo <ファイル> <新しい名前>   # 長辺2000pxへ。EXIFの向きも焼き込む
npm run ig:photo --trim ...                # 上下の黒帯を落とす
npm run ig:photo --crop=35,100 ...         # 上を切り落として被写体を持ち上げる
npm run ig:render                          # 9枚とグリッドを書き出す
```

デザインの定義は `src/instagram9/card.js`、文言は `src/instagram9/posts.js` の1か所だけです。
