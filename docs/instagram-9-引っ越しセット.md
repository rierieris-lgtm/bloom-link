## 0. 先に読んでください（大事な3点）

**1. 日本語の文字は画像生成に任せない。**
画像生成AIは日本語を正しく描けません。実際に試した案では
「充金しよ、あい」「並んなね売もだてか」のような崩れた文字が出ていました。
**文字は必ず `npm run ig:render` で入れます。**
ChatGPTに頼むのは、写真そのものか、写真の構図・世界観の案までにしてください。

**2. AI生成写真を主役にしない。**
確定資料に「本人が実際に撮影した写真をブランドの大きな資産として使う」とあります。
AI生成写真は、構図を探すためのラフや、どうしても素材がない箇所の検討用にとどめます。

**3. 絶対に暗くしない。**
写真全面に暗いフィルター＋白文字の案には戻しません。理由は §3 に実験結果があります。

**4. 01・02はすでに投稿済みです。03はまだ未投稿です。**
投稿済みの2枚が最終的な見本です。仕様と食い違うところがあれば、**投稿済みの2枚が正しい。**
そこから確定したことは §2 にまとめてあります（フッターなし／サブは任意／小さな飾りは可）。
03はまだ動かせるので、グリッド全体を見て型を決められます。

## 3. 文字の置き場所は4種類（ここがリズムをつくる）

**同じ「写真全面」でも、文字をどこに置くかで印象が変わります。**
全部を同じ位置にすると、統一感を通り越して単調になります。

| 置き場所 | 見え方 | 選ぶ基準 |
| --- | --- | --- |
| **下に帯** | 写真は上側。下にアイボリーの帯 | 見せたいものが**上だけ**にあるとき |
| **上に帯** | 文字が上。写真は下側 | 見せたいものが**下だけ**にあるとき |
| **縦割り** | 左がアイボリー、右が写真 | 見せたいものが**片側だけ**にあるとき。02がこの形 |
| **浮かぶ箱** | 文字が箱に入り、写真が四方に残る | 見せたいものが**上にも下にもある**とき。01・03がこの形 |

**帯は必ず画面の端から45%を食います。** だから上と下の両方に見せたいものがある写真では、
どちらを選んでも片方が消えます。**そういう写真は箱にします。**

03がその例です。上にサグラダ・ファミリアの尖塔、下に本人がいます。
上帯にすると尖塔が消えて「装飾的な石壁の前に立っている写真」になり、
下帯にすると本人が消えて「建物だけの観光写真」になります。箱だけが両方を残せます。

**型は好みで選びません。写真のどこに見せたいものがあるかで決まります。**

**面の幅は固定しません。** 写真の被写体がどこから始まるかで決めます。投稿済みの02は約43%。
文字が入る幅が変わるので、見出しの行数もそれに合わせます。

- 見出しが長いとき … **3行**に割って字を小さくする（02がこの形）
- 見出しが短いとき … **2行**のままで大きく置ける

狭い面に長い見出しを2行のまま入れると、語の途中で折り返して読めなくなります。

**面の色はアイボリーか白のどちらでも構いません。** 写真が暖色寄りなら白、寒色寄りならアイボリー。
02のインドは石の色が暖かいので白を使っています。

写真との境目は**硬い直線にせず、46px程度かけて溶かします。**
溶かしてあれば、文字が境目を**1〜2文字ぶん越えても読めます**（02のサブがこの形）。
越える先が写真の暗い部分なら、越えずに面を広げてください。

**帯の位置は好みではなく、写真の被写体がどこにいるかで決まります。**
帯は画面の約45%を覆うので、被写体のいる側に帯を置くと人物が消えます。

帯の境目は、アイボリーから写真へ110pxかけて溶かします（硬い線にしない）。

### 実験の結果（この4通りを試しました）

| 試した型 | 結果 |
| --- | --- |
| 白文字・写真を暗くしない | 空の上は読めるが、建物や人に重なると崩れる。サブコピーは読めない |
| 白文字・写真を暗くする | 読めるが、空の青と地面の明るさが死ぬ |
| 紺文字・写真の明るい部分に置く | 写真が変わると成立しない（緑の中では完全に読めない） |
| **写真全面＋明るい帯** | **どの写真でも読めて、色もそのまま残る** ← これを採用 |

## 4. 9枚のグリッド設計

Instagramのプロフィールは**新しい投稿が左上**に来ます。
01から順に投稿すると、グリッドではこう並びます。

```
09 08 07
06 05 04
03 02 01
```

**だから表紙に 01〜09 の番号は入れません。** 番号が逆から読まれて、
はじめて見た人には左上の「09」が何なのかわからないからです。
順番はキャプション冒頭の「01｜」で伝えます。

物語の順に並べた設計はこうなっています。

```
01 箱        02 縦割り    03 箱         ← 01・02は投稿済み
04 手順の図  05 上帯      06 縦割り
07 上帯3枚   08 数字      09 下帯
```

写真は7枚、文字ものは2枚（04・08）。
**写真を使わない回があるので、素材が揃わなくても投稿が止まりません。**

### 残り7枚をどの型にするか

プロフィールでの実際の並びは逆なので、こうなります。

```
09 下帯      08 数字      07 上帯3枚
06 縦割り    05 上帯      04 手順の図
03 箱        02 縦割り    01 箱        ← 01・02は投稿済み
```

見るのは**辺で接しているところだけ**（左右の隣と、真上・真下）。
斜めは接していないので、同じ型でも気になりません。

この組み合わせだと、**接している12か所すべてで型が違います。**

| 位置 | 接している相手 | だから |
| --- | --- | --- |
| 03 | 02（縦割り）・06 | **箱**。写真の上に尖塔・下に本人がいるので帯が使えない |
| 04 | 01（箱）・05 | 手順の図。箱にしない |
| 05 | 02（縦割り）・04・06・08 | **上帯**。縦割りにしない（02の真上なので接します） |
| 06 | 03（箱）・05・09 | **縦割り**。箱にしない（03の真上なので接します） |

**同じ型を接させない。** これが一番目につきます。
01と03はどちらも箱ですが、間に02が入るので**接していません。**
02と06はどちらも縦割りですが、**斜めなので接していません。**

> 03を最初は上帯にする案で組んでいましたが、**写真のサグラダ・ファミリアが消えるので取り下げました。**
> 03が箱になると、その真上の06は箱にできません。06は縦割りへ移しています。
> **1枚の型を変えると、真上と真下も動きます。**

## 8. ChatGPTに頼むときの文例

### 写真そのものを探す・作る場合

```
以下の条件に合う写真の構図を提案してください。実際に撮影するための指示として書いてください。

用途: Instagram投稿の表紙（1080×1350、4:5）
テーマ: 「AIを使う前に、やることがある。」
必要な条件:
- 明るい自然光。暗い加工はしない
- 被写体が画面の下寄りにあること（上40%に文字を載せるため）
- 手元・キーボード・仕事をしている場面
- 世界観: 明るい／知的／上品／自然／国際的／余白
- 色: 写真の元の色を活かす。青・緑・自然光を残す
```

### 表紙のラフを見たい場合

```
Instagram投稿の表紙のラフを作ってください。

サイズ: 1080×1350（4:5）
構成: 写真を全面に敷き、下側にアイボリー(#FAF8F3)の帯を置く。帯は画面の約45%
文字は帯の中に紺色(#2B5F7A)で置く。写真は暗くしない
下に屋号やタグラインのフッターは入れない

※ 日本語の文字は崩れるので、文字はダミー（■■■■）で構いません。
   実際の文字はこちらで入れます。見たいのは写真と帯のバランスです。
```

### 投稿済みの表紙に合わせてほしい場合

```
すでに投稿した表紙を添付します。これと並べて同じ作品に見える表紙を作ってください。

守ること:
- 1080×1350（4:5）
- 写真は暗くしない。元の色を残す
- 文字はアイボリー(#FAF8F3)の面の上に紺色(#2B5F7A)で置く
- 屋号やタグラインのフッターは入れない
- くすみゴールド(#C9A96E)は罫線と小さな飾りだけ。少量
- 英字はカテゴリー1つだけ。主役は日本語

避けること:
- すでに使った形（浮かぶ箱・縦割り）をそのまま繰り返す
- 全体を暗くする／黒を中心にする
- 装飾を増やす

※ 日本語はダミー（■■■■）で構いません。見たいのは写真と面のバランスです。
```

**日本語をダミーにするのが要点です。** 崩れた日本語が入ったラフは判断に使えません。

## 9. 戻ってくるとき

ラフや写真ができたら、写真ファイルを渡してもらえれば組み込めます。

```bash
npm run ig:photo <ファイル> <新しい名前>   # 長辺2000pxへ。EXIFの向きも焼き込む
npm run ig:photo --trim ...                # 上下の黒帯を落とす
npm run ig:photo --crop=35,100 ...         # 上を切り落として被写体を持ち上げる
npm run ig:render                          # 9枚とグリッドを書き出す
```

デザインの定義は `src/instagram9/card.js`、文言は `src/instagram9/posts.js` の1か所だけです。
