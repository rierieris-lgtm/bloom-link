# Instagram 仕事用アカウント｜最初の9投稿

すべての判断基準は、この一文。

> **仕事を軽くして、人生を広げる。**

コピー・写真・レイアウトを足すときも直すときも、
必ずこの一文に接続できるかを先に確認する。接続できないものは入れない。

---

## 1. どこに何があるか

| 中身 | 場所 |
| --- | --- |
| 9投稿の文言（表紙コピー・本文・ハッシュタグ） | `src/instagram9/posts.js` |
| 表紙のデザイン定義（1080 × 1350） | `src/instagram9/card.js` |
| 制作確認画面 | `src/pages/Instagram9.jsx` → `/instagram9` |
| 書き出したPNG | `public/instagram/01.png` 〜 `09.png` |
| 9枚を並べた確認用 | `public/instagram/grid.png` |
| 表紙用フォント（サブセット） | `public/instagram/fonts/` |

デザインの定義は `card.js` の1か所だけ。
確認画面と書き出しスクリプトは、どちらも同じファイルを読んでいる。
片方だけ直して見た目がずれる、ということは起きない。

## 2. 作業の流れ

```bash
npm run dev          # /instagram9 で9枚まとめて確認
npm run ig:render    # PNGを書き出す（public/instagram/）
npm run ig:render 01 # 番号を指定して1枚だけ
npm run ig:fonts     # 表紙のコピーに新しい漢字を足したときだけ
```

`ig:render` は Playwright を使う。入っていなければ `npm i -D playwright` を先に。
サイト本体のビルドには関係しないので、依存には入れていない。

`ig:fonts` は、表紙に出る文字だけに絞ったフォントを取り込み直す。
ひらがな・カタカナ・英数字は最初から全部入っているので、
表紙コピーに**新しい漢字**を足したときだけ実行すればよい。

流し忘れても大丈夫なようにしてある。
`ig:render` は書き出す前にフォントの文字を確認し、
足りない文字があればその文字を挙げて止まる（豆腐のまま書き出されることはない）。

## 3. 01で確定したルール（02〜09で固定）

制作手順の指示どおり、01でこれを決め、以降は変えていない。

| 項目 | 確定値 |
| --- | --- |
| キャンバス | 1080 × 1350（4:5） |
| 余白 | 左右 90px ／ 上下 96px |
| 番号 | 上左・Cormorant Garamond 300 / 34px / トラッキング .18em |
| カテゴリー | 番号の下・17px / トラッキング .34em・**1枚に1つだけ** |
| コピー | **全変型で下寄せ**・Noto Serif JP 300 / 68〜92px / 行送り1.5 |
| サブコピー | 25px / 行送り1.9 |
| フッター | 「仕事を軽くして、人生を広げる。」＋ BLOOM LINK（くすみゴールド） |
| フッター（09のみ） | 01〜09のインデックス ＋ 「Rie」の署名（Italianno） |
| 基本色 | IVORY `#FAF8F3` / WHITE / NAVY `#2B5F7A` / CHARCOAL `#3A4754` |
| アクセント | くすみゴールド `#C9A96E`（罫線と数字のみ・少量） |
| 写真加工 | `saturate(1.04) brightness(1.03)` のみ。**暗くしない** |

**コピーが下寄せであること**が、9枚を1つの作品に見せている一番の要素。
変型ごとに上寄せ・中央寄せへ変えない。

レイアウトは絶対座標ではなく縦のフレックスで組んである。
コピーの行数を増やしても写真と文字は重ならず、写真側が自動で縮む。

### 写真の上に文字を置くとき

暗いフィルター＋白文字には**戻さない**。
明るいアイボリー面を重ねて、紺文字を読ませる（`.ig-veil-*`）。
上のアイボリー帯は212pxで、ここを削るとカテゴリー名が写真に埋もれる。

## 4. グリッド設計

9枚を並べた状態そのものを1つの作品として設計している。
同じ型が縦にも横にも隣り合わないように配置した。

```
01 額装      02 文字のみ   03 写真全面
04 手順の図  05 問いの列   06 額装
07 3枚組     08 数字       09 着地
```

- **額装** — アイボリー地に写真をはめる。余白そのものがデザイン
- **写真全面** — 全面写真＋明るいアイボリー面
- **帯 / 3枚組** — 左右いっぱいの写真。額装との対比でリズムをつくる
- **文字のみ / 手順の図 / 問いの列 / 数字** — 写真を使わず、タイポグラフィで持たせる

### 04と05の分担

隣り合う2枚なので、役割をはっきり分けている。

| | 04 HOW I WORK | 05 AI & SYSTEM |
| --- | --- | --- |
| 見せるもの | **動作**（何をするか） | **問い**（何を決めるか） |
| 中身 | 整理する → やめる → 任せる → 仕組みにする | 何を残す／AIに／人に／自分が |
| 形 | 線画アイコンの**横**並び | 罫線で区切った**縦**の列 |

「やめる」は04の担当なので、05の問いからは外してある。
縮小して並べたときに別物として読めるよう、横組みと縦組みで分けている。

中央の列（02・05・08）が文字ものになり、写真が外側の列に回る。
9枚を縮小して見たときに、これが縦の背骨として効く。

1枚直すたびに、必ず `/instagram9` のグリッドか `grid.png` に戻って全体を見る。

## 5. 写真の割り当てと、足りていないもの

| No | 使用素材 | 備考 |
| --- | --- | --- |
| 01 | `japan.jpg` | |
| 02 | — | 写真なし |
| 03 | `barcelona.jpg` | バルセロナ |
| 04 | — | 写真なし |
| 05 | — | 写真なし |
| 06 | `chiangmai.jpg` | **要差し替え候補**（下記） |
| 07 | `hawaii.jpg` / `phiphi.jpg` / `malaysia.jpg` | ハワイを含む |
| 08 | — | 写真なし |
| 09 | `malta.jpg` | マルタ |

指示のあった**マルタ（09）・バルセロナ（03）・ハワイ（07）**は入っている。
ウズベキスタンだけで海外イメージを作らない、という条件も満たしている。

### 差し替えが必要なもの

1. **解像度** — いま使えるのは web用に圧縮された最大900×800pxの画像で、
   1080×1350へ引き伸ばして書き出している。**構成を確認するための試作**としては足りるが、
   実際に投稿する前に元データへ差し替えたい。
   `public/travel/` に同名で上書きして `npm run ig:render` を流し直せば、それだけで反映される。

2. **06（PEOPLE）の写真** — いまはチェンマイの親子写真を仮で置いている。
   この回はチーム・人との交流がテーマなので、
   **人が写っている仕事の写真**（チーム、現地の人との交流、日本語学校）に差し替えたい。

3. **ウズベキスタン・インド** — リポジトリに写真がない。
   07の3枚組はこの2地域に差し替えると、より「世界へ広がっている」感じが強くなる。

4. **05（AI & SYSTEM）** — 当初は `windowseat.jpg`（機内・PC）を想定したが、
   写り込んでいるものがビジネスアカウントの1枚目としては判断が要るため外し、
   「AIに渡す前に決める4つの問い」を見せる文字ものにした。
   トリミングでは外せない（瓶とグラスが画面中央にあり、左端のPCしか残らない）。
   仕事風景の写真が用意できれば、帯の型に戻すこともできる。

### 事実確認が必要なコピー

03のサブコピー「17日間で3カ国へ。それでも、仕事は止まらなかった。」は、
別案から取り込んだ数字。**実際の日数・カ国数と合っているか確認してから投稿する**こと。

## 6. 本文（キャプション）

9本とも `src/instagram9/posts.js` に入っている。
`/instagram9` の各投稿に「本文をコピー」ボタンがあり、ハッシュタグまで含めてそのままコピーできる。

ハッシュタグは共通8個＋投稿ごとに2個。共通部分は `hashtagsBase` で一括で直せる。

本文を書くときに守っていること:

- 脱サラ成功物語にしない。会社員時代を否定しない（02）
- 海外ノマド自慢・旅行自慢にしない（03・07）
- AIコンサルアカウントのように見せない。AIは手段として書く（05）
- 数字だけの実績自慢にしない。結論を見せる（08）
- 苦労話に寄せない。40代女性向けだけに狭めない

## 7. やらないこと

- 全体を暗くする／黒中心にする／「高級感＝暗い」と解釈する
- 写真を暗く加工して、無理に統一感を作る
- AI生成写真を中心にする
- 9枚すべてを同じテンプレートにする
- 01〜09を独立した投稿として設計する
- 途中でブランドカラーや軸を変更する
- 英語をデザイン目的で増やす（主役は日本語。英字カテゴリーは1枚に1つまで）
