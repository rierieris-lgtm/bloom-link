## 3. 決まっていること

### 3-1. 本文の書き方（投稿済みの01・02から取った）

実際に投稿された2本を読み直して決めました。**ここから外れると本人の文章に見えません。**

1. **箇条書き（・）を使わない。** 01にも02にも1つもありません。全部が地の文です。
   箇条書きが入ると、体験談ではなく解説記事に見えます
2. **1行は23字まで。** 投稿済みの最長が01で23字、02で22字。スマホで折り返さない幅です
3. **1段落は1〜3行。** 段落の間は必ず1行あけます
4. **抽象語ではなく、具体的な事実。**「4年間の産休・育休」「小学生2人の子育てと、全国への出張」
   「15年以上、抱えていました」。数字と場面があります
5. **心が動いたところは、そのまま書く。**「最終日は、涙が止まりませんでした。」
   説明せず、起きたことだけを置きます
6. **最後は短い一文で言い切る**
7. **敬体と常体は回ごとにそろえる**（01は常体、02は敬体。1本の中で混ぜない）
8. **ハッシュタグは1行ずつ縦に並べる**
9. **「会社を辞めたから」を理由にしない。** 辞めたことを原因として書くと、
   会社員のまま働き方を変えたい人と副業の人が全員はじき出されます。
   変わったのは所属ではなく、**時間の扱い方と頼り方**。そちらを原因に書きます
10. **示せるなら説明しない。** 01・02は結論を説明せず、起きたことだけを置いています
11. **できなかった → できた、で切り返さない。**「でも、行けました」のような書き方は、
    読む人を「できた人／まだの人」に分けます。自慢の形です。
    **悩んでいた側にとどまる時間を長く取る。** そこが読む人と同じ場所です

### 3-2. 中身を決めるときの決まりごと

- **読む人を「会社を辞めた人」だけにしない。** 会社員のまま働き方を変えたい人、
  副業を始めた人、家のことを抱えている人も読む側に置く（**08だけは経営者向けで例外**）
- **並べるものは、読む人が持っているものから。** 時間の使い方・優先順位・
  夫婦の時間・子どもとの過ごし方。お客様や売上から始めない
- **戦略の話は持ち主の回まで取っておく。**
  手放す・任せる・仕組みにする＝**04**／頼ることの怖さ・チームづくり＝**06**／
  関わる人の選択肢まで広げる＝**09**
- **1つの記事を1つの投稿で使い切らない。** 一番強い一行はその回のために残す
- **ハッシュタグは1投稿5つまで。** 1枠目はシリーズのタグ `#仕事を軽くして人生を広げる` で固定
- **サービスのカテゴリー名は使わない**（#業務改善 #経営者の右腕 などはコンサル像に寄る）

### 3-4. 表紙のデザイン（投稿済みの01・02から確定）

| 項目 | 確定値 |
| --- | --- |
| サイズ | 1080 × 1350（4:5） |
| 余白 | 左右 90px ／ 上下 96px |
| 番号 | **表紙に入れない** |
| カテゴリー | 見出しの直上・17px・字間 .34em・**1枚に1つだけ** |
| 見出し | Noto Serif JP 300 / 74〜84px / 行送り1.5 |
| サブ | 25px / 行送り1.9。**任意**（置かない回は罫線も外す） |
| フッター | **入れない**（09の署名「Rie」だけ例外） |
| 色 | IVORY `#FAF8F3` / NAVY `#2B5F7A` / CHARCOAL `#3A4754` ＋ GOLD `#C9A96E` 少量 |
| 写真加工 | `saturate(1.04) brightness(1.03)` のみ。**暗くしない** |

**文字の並びは全枚共通**：カテゴリー → 見出し → くすみゴールドの罫線 → サブ。
この塊が同じ形をしているから、置き場所を変えても9枚が1つの作品に見えます。

**飾りは細い線画だけ。** 03の案にはカテゴリー上の細い罫線＋小さなゴールドの光、
左下に植物の線画が入っています。1枚に多くて2つ。余白の中だけに置き、写真や文字に重ねません。

### 3-5. 表紙の型は写真で決まる

**好みで選びません。写真のどこに見せたいものがあるかで決まります。**

| 見せたいもの | 型 |
| --- | --- |
| 上だけ | 下帯 |
| 下だけ | 上帯 |
| 片側だけ | 縦割り |
| **上にも下にも** | **箱** |

**帯は必ず画面の端から45%を食います。** だから上と下の両方に見せたいものがある写真では、
どちらを選んでも片方が消えます。**そういう写真は箱にします。**

### 3-6. グリッドの型の割り当て

物語の順。

```
01 箱        02 縦割り    03 箱         ← 01・02は投稿済み
04 手順の図  05 上帯      06 縦割り
07 上帯3枚   08 数字      09 下帯
```

**Instagramのプロフィールは新しい投稿が左上に来ます。** 実際の並びは逆。

```
09 下帯      08 数字      07 上帯3枚
06 縦割り    05 上帯      04 手順の図
03 箱        02 縦割り    01 箱
```

**辺で接する12か所すべてで型が違います。** 斜めは接していないので、
01と03が同じ箱、02と06が同じ縦割りでも問題ありません。

**1枚の型を変えると、真上と真下も動きます。**
03を箱にしたので、その真上の06は箱にできず縦割りへ移しました。

## 4. 却下した案と、その理由

**ここが一番大事です。** 一度試して駄目だった案を、また試さないためのリストです。

### デザイン

| 却下した案 | 理由 |
| --- | --- |
| **写真を暗くして白文字を載せる** | 実際の写真で4通り試した。暗くしないと読めず、暗くすると空の青と地面の明るさが死ぬ。**写真全面＋明るい帯**だけが、どの写真でも読めて色も残った |
| **紺文字を写真の明るい部分に置く** | 写真が変わると成立しない（緑の中では完全に読めない） |
| **表紙に 01〜09 の番号を入れる** | グリッドで番号が逆から並ぶ（左上が09）。はじめて見た人には意味がわからない。順番はキャプション冒頭の「01｜」で伝える |
| **フッター「仕事を軽くして、人生を広げる。／BLOOM LINK」** | 表紙の下に説明が居座って写真の余白が死ぬ。本人が作った01・02はどちらも入れていない |
| **ゴールドのベタ矩形を角に置く飾り** | ベタの図形は線画より強く、**写真より先に目に入る**。飾りは線画までにとどめる |
| **9枚すべて同じ型** | 統一感を通り越して単調になる |
| **03を上帯にする** | サグラダ・ファミリアの尖塔が画面の上45%を占めている。帯で丸ごと消えて、装飾的な石壁の前に立っている写真になる |
| **03を下帯にする** | 本人が右下にいる。帯で消えて、建物だけの観光写真になる |
| **03を縦割りにする** | 02が縦割りで、グリッドで隣に来る。同じ形が2枚並ぶ |
| **01に着物の写真** | 正装＋和風建築は料亭の女将に読める。「妻。母。娘。会社員22年。店の経営。」＝**全部**に対して、一番格式のある一つの役割しか写っていない |

### 文章

| 却下した案 | 理由 |
| --- | --- |
| **箇条書き（・）を使う** | 体験談ではなく解説記事に見える。01・02には1つもない |
| **「01〜09で、ひとつの物語になっています」** | 本人が毎回削除していた。連載であることは本文の頭の「01｜」で足りる。着地のあとに案内文が来ると弱くなる |
| **ハッシュタグを横につなげる** | 本文の下に長い青い帯ができて、読み終わりの余韻が消える。**1行ずつ縦に並べる** |
| **#業務改善 #経営者の右腕** | サービスのカテゴリー名。コンサル像に寄る |
| **「17日間で3カ国へ。それでも、仕事は止まらなかった。」**（03のサブ案） | 事実確認が取れない数字だった |
| **「でも、行けました。」**（03） | できなかった話からできた話への切り返し。読む人を「できた人／まだの人」に分ける。**自慢の形** |
| **「会社という所属を離れて、場所の制約が減りました」**（03） | **事実として間違い。**一人旅に行けたのは会社に所属していた頃。しかも伝えたいことの逆になる |
| **「私が育てたいのは後者です」**（06） | 採用側の言い方。読んでいる人が対象外に置かれる |
| **「意図を理解し、仕組みを動かせる人へ」**（06のサブ） | 求人票の一文に見える |
| **「専門知識のなかった私を」**（02） | これから依頼する人に対して、本人の信頼性を下げる |
| **地名を並べる**「マルタで見た／バルセロナで感じた／ハワイで思い出した」（07） | 旅行自慢の書き方。地名は写真が受け持つ |
| **03の末尾に「会社を辞めることだけが方法ではありません」** | 冒頭で事実として示せているので、同じことを二度言うと前半の驚きが薄まる |

- 英語をデザイン目的で増やす（**主役は日本語**。英字カテゴリーは1枚に1つまで）

- 苦労話中心にする
- 40代女性向けだけに狭めすぎる

npm run dev          # /instagram9 で9枚まとめて確認

## 9. 作業のしかたで分かったこと

- **1枚直したら、必ずグリッド全体に戻って見る。** 1枚では成立しても、
  並べると同じ形が隣り合っていることがある
- **画像生成AIに日本語を描かせない。** 「充金しよ、あい」のような崩れた文字になる。
  ラフを頼むときは日本語をダミー（■■■■）にする
- **本人が「なんか好きじゃない」と言ったときは、たいてい形の問題。**
  06・07がそうだった。中身ではなく、箇条書き・行の長さ・抽象度が原因だった
- **本人の言葉をそのまま使うと強い。** 01は本人が全文書き直したもので、
  結果的にこれが9投稿すべての見本になった
