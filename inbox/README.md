# inbox

**過去の会話履歴を置く場所です。**

Claude や ChatGPT の会話は自動で引き継げません。
新しいセッションで作業を続けるときに読むものを、ここに入れます。

## 入っているもの

| ファイル | 中身 | 誰が書いたか |
| --- | --- | --- |
| `claude-history.md` | Claude側の会話で決まったこと・却下した案・事実関係・本人待ちの質問 | Claude |
| `chatgpt-history.md` | ChatGPT側の会話（表紙のデザイン制作） | **未取り込み** |

## 使い方

新しいセッションを始めるときは、**`claude-history.md` の §2（現在地）と §4（却下した案）**
を先に読んでください。§4は、一度試して駄目だった案をまた試さないためのリストです。

## 履歴の追加のしかた

ChatGPT側の履歴は、ChatGPTの画面から書き出してここへ置いてください。
まとまっていなくて構いません。**決まったことと、その理由**が残っていれば足ります。

会話をそのまま貼るより、次の3つが分かる形のほうが役に立ちます。

1. **決めたこと**
2. **却下したことと、その理由**
3. **まだ決まっていないこと**

## 注意

**このフォルダは記録です。作業の正はここではありません。**

- **文章**の正 … `src/instagram9/posts.js`
- **デザイン**の正 … 本人がChatGPTで作った表紙そのもの

履歴と現物が食い違ったときは、**現物のほうが正しい**と考えてください。
`claude-history.md` は、そのときの判断の理由を思い出すためにあります。
